# TNT 演示场景库 (Demo Gallery)

本文档列出 TNT 的所有演示场景，包括使用的技能、前置条件和成功标准。

---

## 场景 1：语音打开记事本

| 项目 | 内容 |
|------|------|
| **使用的技能** | 内置 `ptt`（按讲即谈） |
| **演示目的** | 展示 PTT 语音识别 + 自动执行 |
| **前置条件** | ① PTT 服务正常运行 ② Windows Notepad 可用 ③ 系统音频输入正常 |
| **操作步骤** | ① 点击 PTT 浮动按钮 → ② 说"打开记事本" → ③ 松开 → ④ Notepad 自动打开 |
| **成功标准** | Notepad 窗口在 3 秒内弹出，任务栏无报错 |
| **失败处理** | 如果语音识别失败，可改用键盘快捷键触发，演示继续 |

## 场景 2：格式化剪贴板文本

| 项目 | 内容 |
|------|------|
| **使用的技能** | `clipboard-format-text`（格式化剪贴板文本） |
| **演示目的** | 展示内置技能 + LLM 调用 + 剪贴板读写 |
| **前置条件** | ① `clipboard-format-text` 技能已安装 ② 剪贴板中有待整理的脏文本 ③ LLM 服务可用 |
| **操作步骤** | ① 从网页复制一段脏文本 → ② 打开 TNT 主窗口 → ③ 进入"技能"标签 → ④ 找到并运行"格式化剪贴板文本"→ ⑤ 确认完成 → ⑥ 粘贴到记事本 |
| **成功标准** | 粘贴后的文本无多余空格、无乱码字符、标点统一为半角 |
| **脏文本示例** | `你好！　这是　一段　测　试  文本．．．Ｆｉｘ　ｍｅ！` → 应为 `你好!这是一段测试文本...Fix me!` |

## 场景 3：整理桌面文件

| 项目 | 内容 |
|------|------|
| **使用的技能** | `organize-desktop-files`（整理桌面文件） |
| **演示目的** | 展示自定义 YAML 技能的安装和执行 |
| **前置条件** | ① `organize-desktop-files.yaml` 已编写 ② VS Code（或其他编辑器）可打开 ③ 桌面上至少有一个 .txt/.md/.docx 文件和一张 .png/.jpg 图片 |
| **操作步骤** | ① 在 VS Code 中打开 YAML 文件 → ② 点击 TNT 插件"安装技能"→ ③ 打开 TNT 主窗口 → ④ 进入技能列表 → ⑤ 找到"整理桌面文件"→ ⑥ 运行 → ⑦ 桌面出现"文档_已整理""图片_已整理""其他_已整理"三个文件夹 |
| **成功标准** | 三个文件夹均已创建且位于桌面；文件未移动（dry_run 模式默认开启） |
| **备注** | 如果演示真实移动，需设置 `dry_run: false` 并提前备份桌面 |

## 场景 4：显示系统信息

| 项目 | 内容 |
|------|------|
| **使用的技能** | `show-system-info`（显示系统信息） |
| **演示目的** | 展示 system_info 工具 + LLM 格式化 + clipboard_write 的组合 |
| **前置条件** | ① `show-system-info` 技能已安装 ② LLM 服务可用 |
| **操作步骤** | ① 打开 TNT 主窗口 → ② 进入"技能"标签 → ③ 找到并运行"显示系统信息"→ ④ 确认完成 → ⑤ 粘贴到聊天窗口或文档 |
| **成功标准** | 粘贴内容为 3-5 行中文系统报告，包含 CPU 使用率、内存占用、磁盘空间等信息 |
| **输出示例** | ```
📊 系统报告 (2026-07-02)
• CPU: Intel i7-12700H @ 2.3 GHz — 使用率 23%
• 内存: 32 GB — 已用 12.5 GB (39%)
• 磁盘 C: 512 GB — 已用 256 GB (50%)
``` |
